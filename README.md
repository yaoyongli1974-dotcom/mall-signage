# 商场 · 场馆智能导视系统

面向**商业综合体、购物中心、主题场馆**的触控导视系统：交互式楼层地图、品牌导购、路线导航、点位详情、优惠活动与屏保广告，配套 Web 管理后台。

技术栈与「办公区域引导屏」完全一致：**零第三方依赖**（纯 Node.js `http` + 原生 HTML5 / JS / SVG），双击即跑，适合 55" 触控一体机与局域网部署，也可作为功能验证原型。

## 🗺️ 底图图层与对齐（替换为真实商场 CAD / PNG）

### 对齐原理（为什么天然精确）
底图、店铺方块、设施标记、导航节点、路线**全部使用同一坐标系**：平面为 SVG `viewBox="0 0 1000 700"`，默认 `10px = 1m`。
前台渲染底图时按 `imageRect` 铺放（默认 `0,0,1000,700`，`preserveAspectRatio="none"`），
因此只要底图按同一坐标系制作，就与业务图层**逐像素对齐**（已通过脚本校验：每层 12/12 店铺与底图矩形完全吻合）。

### 用真实商场的 CAD / PNG 替换（3 步）
1. 后台 →「🗺️ 平面编辑」→ 选择楼层 →「底图图层」卡片**上传底图**（PNG / JPG / WEBP / SVG，≤8MB）；
2. 切到「🗺️ 拖拽底图」模式把底图拖到位；用 `X / Y / 宽 / 高` 输入框或「铺满画布」贴合，透明度滑杆用于透视对位；
3. 切回「✋ 拖拽店铺」模式，把店铺色块拖到真实铺位上（松手自动保存）；再在「节点与连线」用「一键生成路网连线」重建动线，并设置起点。

### CAD 导出建议
- **推荐 PNG**：在 CAD 中按**楼板外轮廓**框选，等比导出（长宽比建议 ≈ 1000:700，即 10:7），上传后点「铺满画布」即 1:1 落位。
- **也可 SVG**：导出矢量 SVG 后把 `viewBox` 归一到 `0 0 1000 700`，或用后台缩放参数拉伸对齐。
- ⚠️ 若底图长宽比不是 10:7，**不要强行铺满**——按真实比例设置 `宽/高` 再用 `X/Y` 居中，否则 `10px = 1m` 换算失真，路线距离会不准。
- 单层底图文件名为 `uploads/plan_<楼层ID>.<ext>`；重新生成示例数据不会删除你上传的文件（扩展名不同则互不覆盖）。

### 前台效果开关
「楼层导购」工具栏的**底图**按钮可实时切换底图显隐：开启时店铺色块自动降为半透明"高亮层"，底图的建筑线条与店名透出；关闭时恢复纯色块 + 店名。

## 🖼 素材上传（店铺 Logo · 活动页面 · Banner）

三类素材共用上传接口 `POST /api/upload/asset`，后台对应「选择类型 + 上传文件 / 填外链」的编辑器。

### 1）店铺 Logo ——「后台 · 店铺管理 → 店铺 Logo」
| 项 | 要求 |
|---|---|
| 支持格式 | **PNG / JPG / WEBP / SVG / GIF** |
| 尺寸建议 | **1:1 正方形、≥256×256px**；PNG 或 SVG 透明底更佳 |
| 大小上限 | ≤ 2MB（接口限制 4MB） |
| 展示位置 | 「品牌导购」卡片头像 + 「店铺详情」头部标识；未上传时自动回退为业态图标 |

### 2）活动页面 ——「后台 · 活动管理 → 活动页面素材」
| 类型 | 上传方式 | 大小 / 规格 | 前台展示效果 |
|---|---|---|---|
| 图片 | 上传文件 或 填外链 | ≤4MB，建议 16:9 或 1:1 | 卡片缩略为海报底图；点击后**全屏等比展示**活动海报 |
| 视频 | 上传 MP4 / WEBM / OGG 或 填外链 | ≤40MB，建议 1080p、≤30s | 详情页内嵌播放器，**自动静音播放、可暂停 / 全屏**（服务端支持 Range，可拖进度条） |
| 互动网页 | 直接填 `https://` H5 链接 | — | 详情页以 **iframe 嵌入**，支持抽奖 / 报名 / 小游戏等交互 |

### 3）Banner 素材 ——「后台 · Banner 管理 → Banner 素材」
| 类型 | 上传方式 | 大小 / 规格 | 前台展示效果 |
|---|---|---|---|
| 图片 | 上传文件 或 填外链 | ≤4MB，**建议 1920×480（4:1）** | 作为 Banner **覆盖式背景**（`background-size:cover`），文案叠加在上层并自动加暗色渐变保证可读性 |
| 视频 | 上传 MP4 / WEBM / OGG 或 填外链 | ≤40MB，建议 1080p、≤30s、**静音或无音轨**，按 **4:1 取景** | Banner 内**静音、循环、自动播放**作为动态背景，文案叠加在上层 |
| 互动网页 | 直接填 `https://` H5 链接 | 按 **4:1** 设计版式 | Banner 区域**以 iframe 嵌入**互动页，此时**不再叠加文案**（整块区域交给互动页） |

> 📐 **为什么是 4:1 而不是 16:9？** 首页 Banner 在版式中是一条**宽幅带**（下方还有 6 个快捷卡片），并非整屏。
> 旧版用 `flex: 0 0 46%`（高度 = 可用高度的 46%），**比例会随窗口高度漂移**：1920×1080 → 1868×442（4.23:1）、1920×911 → 1868×364（5.13:1）、4K → 3788×938（4.04:1）。
> 现已把 `.home-hero` 固定为 `aspect-ratio: 4 / 1`（并用 `max-height:52%` / `min-height:150px` 兜底极端窗口），
> 因此在 1366×768 / 1920×1080 / 4K 等常规尺寸下比例恒为 **4:1**，素材规格才可确定。**16:9 的素材直接用会被上下裁掉约 36%**。
> ⚠️ 待机页是全屏 **16:9（1920×1080）**，与首页 Banner 的 4:1 不同，两处素材**不可混用**。

> ⚠️ 互动网页需目标站点**允许被 iframe 嵌入**（未设置 `X-Frame-Options: DENY/SAMEORIGIN`，CSP `frame-ancestors` 未禁止）。若嵌入后空白，说明对方站点有防嵌套限制，改用图片或视频即可。
> 💡 首页 Banner 每 5 秒自动轮播。若包含「互动网页」类型，建议只保留 1 张，避免轮播打断用户交互。
> 🖼 视频建议静音：移动端与部分一体机浏览器要求静音才允许自动播放；视频文件已支持 HTTP Range，可正常起播与拖动。

## 🖥️ 待机页（屏保）自定义轮播 —— 完整实现方案

待机页是**独立于 Banner 的一套配置**（`settings.screensaver`）：无人操作达到触发时间后全屏进入，按「节目单」轮播，轻触任意位置退出。

### 1）可配置项
| 分组 | 配置项 | 说明 / 取值 |
|---|---|---|
| 总开关 | `enabled` | 启用 / 关闭待机页 |
| 触发 | `idleSeconds` | 无操作多少秒进入（与「系统设置 → 待机页触发」同一数值，双向同步） |
| 轮播 | `interval` | 默认停留秒数 / 张（单项 `duration` 可覆盖），3–300s |
| 轮播 | `transition` | 切换方式：`fade` 淡入淡出 / `slide` 横向滑动 / `zoom` 缓慢缩放 / `none` 无动画 |
| 轮播 | `order` | `sequence` 按顺序 / `shuffle` 随机 |
| 轮播 | `loop` | 播完最后一屏：循环继续 / 退出待机页 |
| 视频 | `mute` | 静音（推荐）/ 开启声音 |
| 视频 | `videoMode` | `timed` 按停留时长切换 / `ended` 播放完自动切换 |
| 画面 | `dim` | 额外暗化 0–0.7，提升叠加文案可读性 |
| 显示元素 | `showClock` / `showMallName` / `showHint` / `showProgress` | 时钟 / 商场名 / 触摸提示 / 底部进度条 |
| 点击 | `tapAction` | 点击待机页（图片 / 视频）：`activity` **进入关联活动页**（默认）/ `exit` 退出待机页回首页 |
| 点击 | `pageTap` | 点击 HTML5 互动页：`activity` **整页点击进活动**（H5 不响应点击，默认）/ `interact` 保留 H5 交互并另给角标按钮 |

### 2）支持的内容类型
| 类型 | `type` | 接入方式 | 播放与展示效果 |
|---|---|---|---|
| 图片 | `image` | 上传（PNG/JPG/WEBP/SVG/GIF，≤4MB）或填外链 | **全屏 16:9（1920×1080）** 全覆盖（`cover`）；可选叠加标题 / 副标题 |
| 视频 | `video` | 上传（MP4/WEBM/OGG，≤40MB）或填外链 | 自动播放（静音）；`timed` 到点切换 / `ended` 播完切换；可循环 |
| HTML5 互动页 | `page` | 填 `https://` 链接或站内 `.html` 路径 | iframe 独占整屏，**不叠加任何遮罩与文案**，到点切换 |

> 🔗 每条素材都可**关联一个活动**（`promoId`）。关联后，点击该素材会打开对应「活动详情页」；未关联或活动已被删除时走异常兜底（见第 5 节）。

### 3）轮播切换方式与播放控制
- **切换驱动**：每张按 `duration` 计时；视频 `ended` 模式监听 `media.ended` 事件（另设 4×duration 兜底定时器，避免异常卡死）。
- **过渡动画**：切换方式以类名作用在容器上（`.screensaver.t-fade / .t-slide / .t-zoom / .t-none`），纯 CSS 过渡实现，切屏时重置。
- **进度条**：按本张停留时长以 CSS `transition: width {dur}ms linear` 线性推进，切屏归零重启。
- **资源管理**：切屏时自动**暂停并复位非当前页的视频**，避免后台播放占用 CPU / 带宽。
- **交互退出**：`pointerdown` 任意位置退出并重启空闲计时；互动页内部点击**不会冒泡到外层**（iframe 事件不穿透），因此不会误退出。
- **预览**：访问 `/?ss=1` 直接进入待机页（后台「👁 预览待机页」按钮即跳此地址）。

### 4）各类型素材的接入与管理方式
- 后台左侧「🖥️ 待机页配置」：上半区保存**播放参数**，下半区管理**节目单**。
- 节目单支持：**新增 / 编辑 / 删除 / 启用停用 / ↑↓ 排序**（列表顺序即播放顺序）。
- 素材统一走 `POST /api/upload/asset` 落盘到 `public/uploads/`（命名 `ss_<时间戳>.<ext>`）；页面内也可直接填外链。
- 与 Banner 的关系：**未配置节目单时自动回退**为使用 Banner 内容（兼容旧数据）；一旦配置了节目单则以节目单为准。

### 5）点击跳转与异常处理（关联活动）
点击待机页不再一律"返回首页"，而是按素材的**活动关联**跳转：

| 场景 | 行为 |
|---|---|
| 素材已关联活动且活动存在 | 退出待机页 → **打开该活动的详情页**（`openPromo`），跳转目标由 `promoId` **精确匹配**得到，与素材所属活动一致 |
| HTML5 互动页 · `pageTap = activity`（默认） | iframe 设为 `pointer-events:none`，上覆一层透明点击捕获层 → **整页任意点击都进入关联活动**（H5 自身的点击不再响应） |
| HTML5 互动页 · `pageTap = interact` | 保留 H5 内交互（iframe 事件不冒泡，点 H5 不会误退出）；右下角额外提供「🎁 进入活动详情」角标按钮用于跳转 |
| 素材**未关联活动**（`promoId` 为空） | 待机页底部弹出提示「该待机内容暂未关联活动，即将返回首页」，1.5s 后退出待机页 → **不会"点了没反应"卡住** |
| 关联的活动**已被删除**（悬空 `promoId`） | 提示「关联的活动已不存在，即将返回首页」并同样兜底退出；后台「待机页配置」会用红字标出失效关联并提供清单 |
| `tapAction = exit` | 恢复旧行为：点击即退出待机页回首页 |

> 提示文案会随当前素材动态变化：有关联时显示「轻触进入活动：<活动名>」，未关联时显示「轻触查看（当前内容未关联活动）」。

### 6）相关接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/map` | 返回 `settings.screensaver`（全部配置 + 节目单），前台一次取回 |
| GET/PUT | `/api/screensaver` | 读取 / 保存播放参数（PUT 需鉴权） |
| POST | `/api/screensaver/items` | 新增节目单素材 |
| PUT / DELETE | `/api/screensaver/items/:id` | 修改 / 删除单条素材 |
| POST | `/api/screensaver/reorder` | 传 `{ids:[…]}` 调整播放顺序 |

> 💡 建议：`page` 类型若含复杂交互，停留时长设 20s 以上；一体机上视频务必静音，否则浏览器会拒绝自动播放。

## 🖥️ 多触摸屏内容分发（多屏管理）

不同物理位置的触摸屏各自显示独立内容，由「屏幕标识」区分，后台统一配置与远程下发。

### 1）位置标识方式（屏端如何自报身份）

优先级从高到低，命中即停：

1. **URL 参数**：浏览器首页设为 `http://服务器:4000/?screen=F1-LOBBY`
2. **localStorage 记忆**：首次解析成功的标识会被记住，断网重连自动恢复
3. **本地标识文件**：无法统一设置首页的一体机，把 `public/screen-id.example.json` 复制为该机上的 `public/screen-id.json`，写入 `{"id":"F1-LOBBY"}`
4. 都没有 → 回落**默认界面**（全模块开放、从首页进入，等同升级前行为）

标识仅允许字母 / 数字 / `-` / `.` / `_`，后台保存时自动清洗。

### 2）内容分配规则（共享基础 + 每屏覆盖）

全馆共享楼层 / 店铺 / 设施 / 活动 / Banner / 服务指南等基础数据，每屏仅覆盖展示参数：

| 覆盖项 | 说明 |
|---|---|
| 默认页签 | 启动后自动进入：首页 / 楼层导购 / 品牌导购 / 优惠活动 / 服务指南 |
| 聚焦楼层 | 地图默认打开该楼层（导视屏放在几层就默认显示几层） |
| 模块开关 | 未勾选的模块在该屏顶部导航与首页快捷入口中隐藏 |
| 主题色 | 覆盖该屏强调色（`--accent`），不填跟随全局 |
| 本地点位公告 | 顶部公告条，如「您当前位于一层中庭…」，留空不显示 |
| 启用/停用 | 停用的屏配置不生效（该屏回落默认界面） |

### 3）远程更新与切换

- 屏端每 **15 秒**轮询一次 `GET /api/screen/:id`（公开接口，无需登录）
- 后台**保存修改**或点**「立即下发」**都会令该屏 `rev` +1
- 屏端发现 `rev` 变化即自动重新应用配置 / 切换页签 / 换公告，**无需人工刷新**
- 后台「多屏管理」页提供每屏的预览链接 `/?screen=屏幕标识`，点击即模拟该屏加载效果

### 4）相关接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/screen/:id` | 否 | 屏端取专属配置（合并后 profile + rev） |
| GET/POST | `/api/screens` | 是 | 屏幕列表 / 新增 |
| GET/PUT/DELETE | `/api/screens/:id` | 是 | 单屏读取 / 更新（rev+1）/ 删除 |
| POST | `/api/screens/:id/push` | 是 | 不改内容仅强制下发（rev+1） |

## 🛠 后台使用要点

1. **底图与对齐**：选择楼层 → 上传真实 CAD/PNG 底图 → 「拖拽底图」模式摆正 → 「拖拽店铺」模式把色块拖到真实铺位上，松手自动保存。
2. **平面编辑**：选择楼层后，直接**拖拽店铺方块**调整位置，松手自动保存坐标；右侧可精确输入 x/y/w/h，并可调节底图位置、尺寸与透明度。
3. **新增店铺**：填名称、业态、楼层、坐标尺寸即可；业态决定图标与默认配色，前台按 A-Z 索引与分类自动归类。可另上传**店铺 Logo**（见「素材上传」）。
4. **活动 / Banner 素材**：在活动或 Banner 表单的「素材」区选择类型（图片 / 视频 / 互动网页）后上传文件或填外链，保存即在前台生效。
5. **路网维护**：新店铺加入后，到「节点与连线」为其**放置/连接导航节点**，或点「一键生成路网连线」按坐标近邻自动补线；跨层需 `floor` 类型连线。
6. **起点设置**：导视屏所在位置设为起点，前台路线即从该点出发。
7. **待机页**：在「🖥️ 待机页配置」维护**播放参数**与**节目单**（图片 / 视频 / HTML5 互动页），可逐条设停留时长、**关联活动**、启用停用与播放顺序；若关联的活动被删除，页面顶部会用红字列出**失效关联**清单。点「👁 预览待机页」即时查看（等价于访问 `/?ss=1`）。

## ⚠️ 部署与安全说明

- 当前鉴权为明文 token（等于管理密码）+ HTTP，**仅适合本机/局域网**。
- 若需公网部署：请加 **HTTPS 反向代理**、更换强密码、并考虑改为会话化/加密的鉴权方案。
- 数据写入为**整体落盘**（`data/db.json`）；多标签页同时编辑同一数据可能 last-write-wins，请避免并发编辑。
